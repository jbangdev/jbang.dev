//DEPS com.github.lalyos:jfiglet:0.0.9

import com.github.lalyos.jfiglet.FigletFont;

class hello {
  public static void main(String... args) throws Exception {
    var msg = args.length > 0 ? args[0] : "Hello JBang!";
    System.out.println(FigletFont.convertOneLine(msg));
  }
}

Why JBang

Everything you need to script in Java

No pom.xml, no build.gradle, no manual JDK setup—just write a single file and run it anywhere.

Embedded Dependencies

Declare Maven dependencies directly in your source file with //DEPS or @Grab. JBang resolves and caches them automatically.

//DEPS info.picocli:picocli:4.7.6
//DEPS org.slf4j:slf4j-simple:2.0.12

Install & Run Anywhere

Runs on Windows, Linux, macOS, Docker, GitHub Actions, Maven, and Gradle—even directly from a URL or GitHub Gist.

jbang https://jbang.dev/examples/hello.java
Get JBang

No Java? No Problem!

If no JDK is installed on the machine, JBang automatically downloads and configures the right Java version for you.

//JAVA 21+
//JAVAC_OPTIONS --enable-preview

Java 8 and Higher

Use any Java version from 8 to the latest release—switch per script with a single //JAVA directive.

jbang --java 21 myscript.java

JBang AppStore

Discover community CLI tools or publish your own directly from any Git repository using jbang-catalog.json.

jbang app install mcp@jbangdev
